# 简记｜个人记账网页

## 如何运行
1. 解压 `个人记账网页.zip`。
2. 打开文件夹，双击 `index.html`。
3. 网页会在默认浏览器中打开，不需要安装软件或注册账号。

## 如何使用
- 点击“支出”或“收入”切换记账类型。
- 输入金额，选择分类和日期；备注可以不填。
- 点击“保存这笔记录”。
- 页面上方会自动更新总收入、总支出和结余。
- 在“历史记录”中搜索、按类型或月份筛选，也可以删除单条记录。
- 数据自动保存在当前浏览器的本地存储中。

## 文件说明
- `index.html`：网页结构。
- `style.css`：颜色、布局和手机适配等外观。
- `app.js`：添加、保存、筛选、删除和统计等功能。
- `tests/test.js`：主要计算和筛选功能测试。

## 重要提醒
数据保存在当前浏览器、当前设备中。清除浏览器网站数据、换浏览器或换设备可能导致记录丢失。建议定期备份；目前此入门版本没有云同步功能。
